## @asaddu/pdfme-common

> Fork of [@pdfme/common](https://www.npmjs.com/package/@pdfme/common) maintained by [Asaddu](https://github.com/Asaddu/pdfme).

This library provides shared types, constants, and utility functions used across the [@asaddu/pdfme-ui](https://www.npmjs.com/package/@asaddu/pdfme-ui) and [@asaddu/pdfme-generator](https://www.npmjs.com/package/@asaddu/pdfme-generator) packages. The shared types include definitions for templates and other commonly used structures.

For the complete documentation of pdfme, please refer to [this link](https://pdfme.com/docs/getting-started).
